# QuickSave

Quicksave and quickload hotkeys.

| Key | Action                                                     |
| --- | ---------------------------------------------------------- |
| F5  | Quicksaves the game. Keeps the last 5 by default.          |
| F9  | Loads the newest quicksave. Also works from the main menu. |

F5 and F9 do nothing while a build menu category is open.

If [CompressSave](https://thunderstore.io/c/dyson-sphere-program/p/soarqin/CompressSave/) is installed with compression on, quicksaves are compressed.

Change the keys and the number of quicksaves to keep in `BepInEx/config/com.geostyx.dsp.quicksave.cfg`.

See also: [CameraMemory](https://thunderstore.io/c/dyson-sphere-program/p/Geostyx/CameraMemory/)

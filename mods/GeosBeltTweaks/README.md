# GeosBeltTweaks

Adds half-grid snapping, sloped belt starts, height and tier matching, and whole-belt chain upgrades.

| Tweak                         | Effect                                                                                                                            |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Belt preview tilt             | Belt previews show slope and tilt.                                                                                                |
| Match starting belt height    | New belts start at the height of the belt or splitter you drag from.                                                              |
| Match starting belt tier      | Extending a belt selects its tier.                                                                                                |
| Toggle belt surface height    | Numpad 0 toggles between the surface and the previous height in the belt tool. It's the game's reset-height key.                  |
| Half-grid belt snapping       | `` ` `` toggles half-grid snapping in the belt tool.                                                                              |
| Slope from start              | Numpad 1 toggles sloped belt starts in the belt tool. The game normally keeps the first segment flat.                             |
| Base building pause           | Numpad 2 pauses building by Battlefield Analysis Bases on your current planet while the belt tool is open. Press again to resume. |
| Remember belt free-angle mode | Free-angle mode (R) stays on when you reopen the belt tool.                                                                       |
| Unlimited chain upgrade range | Chain upgrades reach the whole belt, ignoring build range.                                                                        |
| Chain upgrade across tiers    | Chain upgrades continue through tier changes.                                                                                     |

Each save remembers half-grid snapping, slope from start, the base building pause, and free-angle mode.

In a new save or one from before you installed this mod, half-grid snapping, slope from start, and the base building pause are off until you press their keys. Turn off any other tweak or change a key in `BepInEx/config/com.geostyx.dsp.geosbelttweaks.cfg`.
